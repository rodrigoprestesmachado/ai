# AI Agents

**AI Agents** são interfaces anotadas com `@Agent` que tomam decisões autônomas e executam ações via tools. Diferente de um AI Service conversacional, um agente é projetado para **agir**: decidir se uma operação é necessária, invocar ferramentas e colaborar com outros agentes em workflows.
{: .fs-3 }

Este trilho cobre a **Section 2 (Agentic Workflows)** do [Quarkus LangChain4j Workshop](https://quarkus.io/quarkus-workshop-langchain4j/section-2/step-01/), usando o módulo `quarkus-langchain4j-agentic`.
{: .fs-3 }

> **Pré-requisito:** conclua o trilho [AI Services](aiservices/) antes de começar. Os agentes reutilizam conceitos de system messages, tools e MCP aprendidos na Section 1.
{: .fs-3 }
